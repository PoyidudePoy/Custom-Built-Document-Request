# Custom-Built Document Request System

The Custom-Built Document Request System is a capstone project for our finals way back 2024

### ⚠️ DISCLAIMER:
This project was developed strictly for academic purposes. It is not intended to promote any products, nor is it associated with any unauthorized or commercial use of the university's name.

## 🚀 Key Features
* **Online Request System:** The primary purpose of this capstone project is to provide a seamless, web-based platform for requesting official documents online.
* **Request Tracking Dashboard:** A dedicated request panel that allows users to view, monitor, and track the status of all their submitted requests in real-time.
